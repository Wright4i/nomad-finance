# Module 13 — Tags and rules

Status: later

A tag is a label on a posting, such as Taxable 1. A posting can carry more than one tag.

A rule is if-then. The if is the payee, the memo, or the amount. The then renames the payee, sets the category, or adds a tag. Payee entry autocompletes from payees already stored.

Demo seed: one tag, and one rule that sets Road cushion when the payee is Payee 1.

Requires postings.
