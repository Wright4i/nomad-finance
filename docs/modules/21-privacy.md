# Module 21 — Privacy

Status: later

Mask hides balances, net worth, and category amounts until you reveal them. Export writes the SQLite file, or a JSON or CSV copy of it, onto this machine. Delete removes the owner's books after a modal confirm. Demo's reset stays the separate demo action.

This module does not depend on postings. It stays `later` while categories are `next`.

Demo seed: the mask control, shown on Demo. Export and delete are exercised against the throwaway test database, never against the owner's file.
