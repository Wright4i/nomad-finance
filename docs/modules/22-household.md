# Module 22 — Household

Status: dropped

Dropped. Leave this note so the idea is not rebuilt by accident.

A second login would share envelopes with the owner, and some accounts would stay hidden from that person. That contradicts [owner and Demo](../adr/0008-owner-and-demo.md): Demo is the sample user, and the owner is the only person who keeps the real books. An ADR would have had to say how a household member differs from Demo. The module is dropped.

Demo stays the sample user. It is not the household member.

The ADR was never written. The module stays dropped.
