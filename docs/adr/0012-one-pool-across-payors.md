# One cash pool across payors

Each payor already has its own period. Available-to-assign stays one number for the books: checking, savings, and cash, converted, minus every assignment in an open period. An assignment is stored on one payor's period, and that same pool covers all of them. A closed period keeps its rows. When the next period opens, that payor's assignments carry in. A pool per payor would split cash the accounts do not split. Rollover, later, decides what a negative assignment does. Until then an assignment is zero or more.
