# A needed-by-date target counts one pay cycle

The gap is the target amount minus the category amount, and that amount is the sum of open assignments on every payor. Dividing the gap still needs a single series of pay periods. The target names one pay cycle for that count: each period that starts on or before the date, including the open one. An irregular cycle has no further periods to invent, so the count stops after the open period and its next payday. A target balance is not divided, because it has no date.
