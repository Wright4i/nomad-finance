# One pay cycle per payor

The books used to keep a single pay cycle, and a second paycheck was only an edit to a cash balance inside that period. That hides a second payday. A payor is a named source of pay, and each payor has one cycle. A second paycheck from the same payor still belongs in that payor's period. Budget, when it is built, assigns into one of these open periods rather than a single shared period.
